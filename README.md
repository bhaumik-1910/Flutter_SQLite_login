# 🔐 Flutter SQLite Login App

This is a **Flutter application** that demonstrates **local authentication and data storage using SQLite**.  
The app uses the **sqflite** plugin to store user data locally on the device and provides basic login and user management features.

SQLite allows your app to **store structured data locally** without requiring an online backend. :contentReference[oaicite:0]{index=0}

---

## 🌟 Features

- 📍 User login with local SQLite database  
- 🛠 CRUD operations for user data  
- 💾 Local data persistence using `sqflite`  
- ⚛️ Simple and responsive Flutter UI  
- 📱 Works offline

## ⚙️ Getting Started

### 1️⃣ Install Flutter
Make sure Flutter is installed and setup:
```bash
flutter --version
```


### 2️⃣ Clone the repository
```bash
git clone https://github.com/bhaumik-1910/Flutter_SQLite_login.git
cd Flutter_SQLite_login
```


### 3️⃣ Install dependencies
```bash
flutter pub get
```

### 4️⃣ Configure API Endpoint
Open api_service.dart and set your upload API URL:
```bash
const String uploadUrl = "https://your-api-endpoint.com/upload";
```

### 5️⃣ Run the app
Android / iOS / Web
```bash
flutter run
```
